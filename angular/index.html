🅰️ Angular · from “why is it checking everything?” to “here is the measured fix”

Learn how Angular decides what to update — and how to keep it fast and correct.

One continuous story: components and templates, change detection and zone.js, OnPush and signals, control flow, RxJS, dependency injection, forms, routing, deferrable views and server rendering, and a debugging playbook. Every page has a before-and-after picture and a debug checklist. Written for modern Angular (standalone components, signals, built-in control flow).
