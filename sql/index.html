Learn to read what the database really did — then make it faster.

Not a list of tuning tricks. One continuous story: a query’s journey, how data sits on disk, indexes, execution plans, statistics, joins, and a debugging method you can use on any slow query. Every page has a before-and-after plan you can compare. Written for SQL Server and Azure SQL (T-SQL); the thinking transfers to other engines.
