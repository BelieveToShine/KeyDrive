Concept 4 of 29 · 📚 Stack & heap

The warehouse and the claim ticket.

What new does step by step: it finds room on the managed heap, prepares the object and hands back an address you keep on the stack.

❓ "What happens in memory when you write new Person()?"
👁 See it first
🎯 new builds the object on the heap and gives you back its address.
🌍 In real life

🏬 A warehouse: you hand over a parcel, they find shelf space, put it there and give you a claim ticket with its shelf number. You keep the ticket (the reference); the parcel stays in the warehouse (the heap).

If you lose every copy of the ticket, nobody can fetch the parcel — the warehouse (the garbage collector) can eventually clear the shelf.

🔤 Strings and arrays are heap objects too
🔬 Hidden bookkeeping (teaching picture)

Besides your fields, every heap object carries a little hidden information, such as which type it is (this is how the runtime knows which methods to call — page 16). The exact layout and sizes are runtime internals, so this lab draws them only as a simple picture and never quotes byte sizes.

🧪 Tiny code
class Person { public string Name; public int Age; }

var p = new Person();     // 1) room on the heap  2) Name=null, Age=0
                          // 3) constructor runs  4) address stored in p
p.Name = "Asha";          // follow the address and change the object

Fields get default values (0, false, null) before your constructor code runs.

♻️ Who clears this memory?

The garbage collector, later, once no variable (and nothing else reachable) holds the address. Setting p = null; only removes one ticket; the object is freed only if no other reference remains. You never free heap memory by hand in C#.

🎯 Check yourself
▾ new Person() returns the object itself.

❌ Wrong. It returns a reference (address) to the object.

▾ Fields of a new object start at default values (0, null, false).

✅ Right. Yes, before the constructor body runs.

▾ Setting p = null immediately frees the object.

❌ Wrong. It drops one reference; the GC frees the object later, if nothing else points to it.

🔥 Interview recall
  • new: reserve room on the heap → default values → constructor → return address.
  • The variable holds the address; the object is on the heap.
  • You do not free heap memory yourself; the GC does.
🎤 Say this in an interview
“new allocates the object on the managed heap, zero-initialises its fields, runs the constructor and returns a reference, which the variable holds. The garbage collector reclaims it when no references remain.”
⚠️ Common trap

Thinking = null “deletes” the object. It only removes that variable’s reference.
