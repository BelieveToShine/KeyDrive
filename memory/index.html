🗂️ Which memory holds what

A simplified map you will refine page by page. (The exact placement is a runtime detail; each page says what Microsoft documents and what is a teaching simplification.)

PlaceTypically holdsCleared by
📚 Stack (one per thread)method calls, local variables, referencespopped when the method returns
🏠 Managed heapobjects created with new, arrays, strings, boxed valuesthe garbage collector (generations 0, 1, 2 + large object heap)
📌 Static datastatic fields and type informationlives as long as the app (until the app domain / process ends)
🧵 Otherthread-local data, async state machinesdepends — covered in the Threads and async pages
