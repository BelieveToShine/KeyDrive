Ship compartments: one flooded part must not sink the rest.

The Bulkhead pattern: isolate resources into separate pools so a failure or overload in one part does not take everything down.

❓ "What is the Bulkhead pattern?"
👁 See it first
🎯 Give each part its own separate pool of resources, so one overloaded part cannot starve the others.
🌍 In real life

🚢 A ship’s hull is divided into watertight compartments (bulkheads). If one floods, the water stays in that compartment and the ship keeps floating.

The Azure Architecture Center lists Bulkhead among its cloud design patterns (isolating elements into pools so that if one fails, the others continue to function).

🔧 The pattern fixes it
🧪 Tiny code
// One limiter per dependency instead of one shared pool
var checkoutLimit = new SemaphoreSlim(3);
var reportsLimit  = new SemaphoreSlim(3);

async Task<T> Run<T>(SemaphoreSlim limit, Func<Task<T>> call)
{
    if (!await limit.WaitAsync(TimeSpan.FromMilliseconds(200))) throw new TimeoutException("compartment full");
    try { return await call(); } finally { limit.Release(); }
}

Libraries such as Polly offer a ready-made bulkhead policy; the idea is a limit per dependency.

🎯 Spot it: is the pattern a good fit?
▾ One slow dependency could starve unrelated features

✅ Good fit. Isolate it in its own pool.

▾ A single small app with one dependency

❌ Overkill. Nothing to isolate.

▾ Pair with Circuit Breaker and Retry for a resilient call path

✅ Good fit. They complement each other.

▾ Pools so tiny that normal load is rejected

❌ Overkill. Size them from real traffic.

👀 How to spot the need in your own code
If you see…Do this
A shared thread or connection pool used by unrelated featuresOne feature can exhaust it.
🔥 Interview recall
  • Bulkhead = isolate resources into separate pools.
  • Limits the blast radius of one slow dependency.
  • Works with Circuit Breaker and Retry.
🎤 Say this in an interview
"The Bulkhead pattern isolates resources — thread, connection or call limits — per dependency or feature, so one slow or failing part can’t exhaust shared capacity and take everything down, like watertight compartments in a ship."
⚠️ Common trap

Pools sized by guess. Measure first.
