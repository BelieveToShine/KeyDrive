A forest of trees: store the same picture once.

The Flyweight pattern: share the repeated parts of many similar objects to fit more in memory.

❓ "What is the Flyweight pattern?"
👁 See it first
🎯 Share the parts that are the same across many objects, and keep only the parts that differ inside each object.
🌍 In real life

📚 A school gives each pupil their own name tag but there is only one copy of the textbook on the shelf that everyone reads. You would not print the whole book for every pupil.

refactoring.guru: Flyweight lets you fit more objects into the available RAM by sharing common parts of state between multiple objects instead of keeping all of the data in each object.

🔧 The pattern fixes it
🧪 Tiny code
class TreeType(string name, byte[] texture) { }           // the heavy, shared part

class TreeTypeFactory
{
    private static readonly Dictionary<string, TreeType> _types = new();
    public static TreeType Get(string name) =>
        _types.TryGetValue(name, out var t) ? t : _types[name] = new TreeType(name, LoadTexture(name));
}

record Tree(int X, int Y, TreeType Type);                  // small: position + a reference to the shared part

The shared part is called intrinsic state; the part that differs per object is extrinsic.

🎯 Spot it: is the pattern a good fit?
▾ Hundreds of thousands of similar objects and memory is tight

✅ Good fit. Share the repeated data.

▾ A few dozen objects

❌ Overkill. Not worth the complexity.

▾ The shared part never changes (read-only)

✅ Good fit. Shared data must be safe to share.

▾ Every object differs completely

❌ Overkill. Nothing to share.

👀 How to spot the need in your own code
If you see…Do this
Many objects holding identical big fields (images, meshes, strings)Move that data into a shared object.
🔥 Interview recall
  • Flyweight = share common (intrinsic) state; keep unique (extrinsic) state per object.
  • Saves memory with huge numbers of objects.
  • Shared parts should be immutable.
🎤 Say this in an interview
"Flyweight saves memory by sharing the common, read-only part of many similar objects — one texture for ten thousand trees — and keeping only the small unique part, like position, in each object."
⚠️ Common trap

Mutating shared state. Everyone sees the change.
