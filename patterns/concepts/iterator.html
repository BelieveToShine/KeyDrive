The Iterator pattern: visit every item of a collection one at a time without exposing how it is stored. It is what foreach uses.

❓ "What is the Iterator pattern and how does foreach use it in C#?"
👁 See it first
🎯 Give every collection the same “is there a next? give it to me” interface, so one loop works for all.
🌍 In real life

📻 A radio’s “next station” button works the same whether the stations are stored in a list or a ring. You do not need to know how the radio stores them.

refactoring.guru: Iterator allows sequential traversal through a complex data structure without exposing its internal details.

🔧 The pattern fixes it
🧪 Tiny code
IEnumerable<int> Evens(int max)            // a custom iterator with yield
{
    for (int i = 0; i <= max; i += 2) yield return i;
}

foreach (var n in Evens(10)) Console.Write(n + " ");      // 0 2 4 6 8 10
foreach (var s in new List<string> { "a", "b" }) { }       // same loop for any IEnumerable

In C#, foreach works on anything that implements IEnumerable/IEnumerator; yield return writes an iterator for you.

🎯 Spot it: is the pattern a good fit?
▾ You write a custom collection and want foreach to work

✅ Good fit. Implement IEnumerable (or use yield return).

▾ A plain List<T>

❌ Overkill. Already iterable.

▾ You want lazy, on-demand items

✅ Good fit. yield return produces items one at a time.

▾ You need random access by index

❌ Overkill. An iterator is sequential.

👀 How to spot the need in your own code
If you see…Do this
Callers reaching into a collection’s internal arrays or nodesExpose an iterator instead.
🔥 Interview recall
  • Iterator = sequential access without exposing internals.
  • C#: IEnumerable/IEnumerator and yield return power foreach.
  • Lazy and sequential only.
🎤 Say this in an interview
"Iterator gives sequential access to a collection without exposing its structure. In C#, foreach is built on IEnumerable and IEnumerator, and yield return lets me write an iterator that produces items lazily."
⚠️ Common trap

Changing a collection while iterating. It throws or behaves oddly.
