A game save: take a snapshot, go back to it later.

The Memento pattern: save and restore an object’s state without breaking its privacy.

❓ "What is the Memento pattern and how does it relate to undo?"
👁 See it first
🎯 Let the object itself save a sealed snapshot of its state, and hand it back later to restore itself.
🌍 In real life

🎮 In a video game you save at a checkpoint. The save file is a sealed snapshot; the game itself knows how to load it. The save menu does not need to understand the game’s insides.

Memento is listed in the classic behavioral catalog; this page paraphrases its usual intent (save and restore state without exposing internals).

🔧 The pattern fixes it
🧪 Tiny code
record EditorSnapshot(string Text);                       // sealed state

class Editor
{
    public string Text { get; private set; } = "";
    public void Type(string s) => Text += s;
    public EditorSnapshot Save() => new(Text);             // the owner makes the snapshot
    public void Restore(EditorSnapshot s) => Text = s.Text; // and restores from it
}
var history = new Stack<EditorSnapshot>();
var ed = new Editor(); ed.Type("hello"); history.Push(ed.Save()); ed.Type(" world"); ed.Restore(history.Pop());

Command + Memento together give robust undo: commands record what to reverse, snapshots record what to restore.

🎯 Spot it: is the pattern a good fit?
▾ Undo/redo or checkpoints where internals must stay private

✅ Good fit. Snapshots keep encapsulation.

▾ State is tiny and public

❌ Overkill. Just copy it.

▾ Snapshots are huge and frequent

❌ Overkill. Memory cost: consider storing only changes (Command).

▾ Saving game or document states

✅ Good fit. The classic use.

👀 How to spot the need in your own code
If you see…Do this
External code copying private fields to “back them up”Let the object make its own snapshot.
🔥 Interview recall
  • Memento = the owner creates and restores snapshots; others only store them.
  • Pairs with Command for undo.
  • Cost: memory for many snapshots.
🎤 Say this in an interview
"Memento lets an object save a sealed snapshot of its own state and restore it later, so undo works without exposing private fields. A caretaker stores the snapshots; I watch memory use and often pair it with Command."
⚠️ Common trap

Memory blow-up. Many full snapshots add up.
