Concept 12 of 17 · 🤖 Acting on goals

Memory carries what happened forward, instead of starting blank every step.

The agent loop can act and observe. Memory is what lets it actually build on what it already did, instead of relearning the same thing every iteration.

❓ "Isn't a bigger context window the same thing as memory?"
👁 See it first
🎯 Memory = carrying what happened in earlier steps (or sessions) forward, instead of starting blank every time.
📖 Why did this need to exist?

An agent restarting blank on every loop iteration — or every new session — can't build on what it already learned or did. It might repeat a search it already ran, forget a decision it already made, or lose all context the moment a conversation ends.

Memory carries relevant information forward — within one multi-step task, and if needed, across separate sessions — so progress actually accumulates instead of resetting every step.

▾ Go one level deeper (60 seconds)

Memory usually operates at two different timescales: short-term memory holds what's relevant within the current task or conversation (often just kept in the model's context); longer-term memory persists across separate sessions (stored somewhere and retrieved when relevant, often using the same kind of meaning-based search RAG uses).

Both exist to solve the same problem — starting blank — just over different spans of time.

🔥 Interview recall
  • Memory carries context forward across loop iterations or sessions.
  • It exists because restarting blank means repeated work and lost context.
  • Short-term memory covers one task/conversation; long-term memory persists across sessions.
  • Memory is deliberate storage + retrieval — not the same as just a bigger context window.
🎤 Say this in an interview
"Memory carries relevant information forward so an agent doesn't restart blank on every loop iteration or session. Short-term memory covers the current task; long-term memory persists across sessions and is usually retrieved by relevance rather than kept in full, all the time."
⚠️ Common trap

A bigger context window isn't the same thing as memory. A large context window lets you fit more raw history in front of the model, but it still has to end somewhere, and stuffing it with everything gets expensive and noisy. Memory usually means deliberately deciding what's worth storing and retrieving, not keeping everything verbatim forever.

▾ 💻 Tiny illustrative example 
# Memory carried into and updated by each loop iteration
memory = load_memory(session_id)   # whatever was stored from before

step   = plan(goal, state, memory)      # planning now sees prior context
result = act(step)
memory = update_memory(memory, step, result)  # save what happened, for next time

Illustrative shape only — real memory systems add summarization and relevance-based retrieval around this core idea.
