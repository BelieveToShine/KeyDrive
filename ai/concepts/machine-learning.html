Machine Learning is the actual process that does the learning AI promised.

The last page said "AI learns from examples instead of following rules." Machine Learning is the field that answers the obvious next question: learns how, exactly?

❓ "What is machine learning, and how is it different from just 'AI'?"
👁 See it first
🎯 Machine Learning = a model adjusts its own parameters from data until it captures a pattern; then that pattern gets reused on new inputs.
📖 Why did this need to exist?

Saying "the system should learn from data" is a goal, not a method. Machine Learning is the actual toolbox for doing that: a family of algorithms that adjust their own internal parameters from data until they capture a useful pattern.

There isn't just one way to learn from data. This page's example — labeled (input, correct-answer) pairs like the house examples above — is supervised learning, the easiest one to see clearly, but it isn't what "ML" means by default. Three other major flavors exist, shown below. All of them end the same way: a trained model — a reusable thing that turns a new input into an output, without anyone hand-coding that specific input.

🏷️ Supervised

Learns from labeled (input, correct-answer) pairs — this page's house-price example.

🔍 Unsupervised

Finds structure in unlabeled data — e.g. grouping similar customers together.

🪞 Self-supervised

Generates its own training signal from the data itself — how most LLMs are pretrained.

🎮 Reinforcement

Learns from a reward signal instead of a labeled answer — try an action, get a score, adjust.

▾ Go one level deeper (60 seconds)

The simplest possible picture: imagine you have house sizes and their sale prices for a hundred houses, and you want to guess the price of house #101. A machine learning algorithm can find the line that best fits those hundred points — bigger house, higher price — and that line is the trained model. Feed it house #101's size, and it reads the price straight off the line.

Real ML models are far more complex than one line, but the shape of the idea is identical: find a mathematical relationship in the examples you have, then reuse that relationship on inputs you haven't seen. "Deep Learning" — later in this journey — is what happens when you stack many such relationships into layers instead of using just one. Take "many stacked lines" as a teaching analogy for the shape of the idea, not a literal description — the actual building block a real deep network stacks (weights, a sum, a non-linear bend) is covered properly in Neural Networks.

  • No labels available

  • Exploring data you do not understand yet
⛔ Look elsewhere when
  • You need a specific, known answer

🪞 Self-supervised

the data supplies its own signal✅ Pick it when
  • Huge amounts of raw text or images
  • Pretraining large models
⛔ Look elsewhere when
  • Small, narrow problems

🎮 Reinforcement

learns from a reward✅ Pick it when
  • Sequences of actions with a score at the end
  • Games, control, tuning behaviour
⛔ Look elsewhere when
  • No safe way to try actions and score them

🔥 Interview recall
  • ML is the concrete "how" behind AI's "learn from data" idea.
  • Four recognized kinds: supervised, unsupervised, self-supervised, reinforcement — not just labeled examples.
  • Training = fitting a model to examples, done once (or periodically), often expensive.
  • Inference = using the already-trained model on a new input, done constantly, needs to be fast.
  • A "model" is just the reusable result of training — not the algorithm itself.
🎤 Say this in an interview
"Machine learning is a family of algorithms that adjust their own parameters from data — from labeled examples in supervised learning, from structure in the data itself for unsupervised learning, from the data generating its own training signal in self-supervised learning, or from a reward signal for reinforcement learning — until they capture a useful pattern, then reuse that trained model on new inputs. Training is usually the more expensive, upfront step; inference is the fast, repeated step that actually runs in production."
⚠️ Common trap

Machine Learning and Deep Learning are not two different things — they're nested, both inside the broader field of AI. AI is the overall goal: systems that perform tasks requiring intelligence, by whatever means. Machine Learning is one major approach — currently the dominant one — where the system learns from data. Deep Learning is a specific kind of Machine Learning that uses many-layered neural networks. Every deep learning system is machine learning; not every machine learning system is deep learning; and not every AI system is machine learning, even though most modern ones are.

▾ 💻 Tiny illustrative example 
# A tiny, real ML idea: fit a line through (size, price) examples
sizes  = [800, 1200, 1500, 2000]   # training examples
prices = [150,  210,  255,  320]   # their known answers ($1000s)

# TRAINING: find the line that best fits these points
model = fit_line(sizes, prices)      # -> e.g. price ≈ 0.085 * size + 82

# INFERENCE: use the trained line on a brand-new house size
predicted_price = model.predict(1750)  # the model never saw 1750 during training

Real models rarely fit a single straight line, but this is the exact shape of what training and inference mean everywhere else in this journey.
