Concept 1 of 19 · 🎓 Foundations

AI is the broad goal — machines doing things that normally need human intelligence.

Machine learning is the approach that now powers most of it, but it's not the only one, and it isn't the definition of AI itself — get that distinction right before anything else, because this whole journey follows the ML path on purpose.

❓ "How would you explain, in one sentence, what AI actually is?"
👁 See it first
🎯 AI = systems built to do things that normally need human intelligence; Machine Learning — learning from data instead of hand-written rules — is the approach that now powers most of them.
📖 Why did this need to exist?

"Artificial intelligence" has never meant just one technique. Hand-written rule and expert systems, search and planning algorithms, logic-based reasoning — all of these are genuinely part of the field, and none of them require a system to learn from data. AI is the goal (systems that perform tasks requiring intelligence); these are different means to it.

Machine learning is one of those means, and it works differently: instead of a person writing down every rule by hand — "if the email contains 'win a prize', mark it spam" — the system learns the pattern from examples. That shift turned out to scale far better to problems with too much real-world variation for anyone to hand-write rules for, which is why ML now dominates most practical AI systems, and why this journey follows the ML path specifically from here on.

▾ Go one level deeper (60 seconds)

A calculator, a sorting algorithm, a traffic-light timer are built from rules a person designed and don't change behavior based on data — genuinely useful, but not usually what anyone means by "AI" today, since they don't perform tasks that need much intelligence in the first place. Classical rule-based and expert systems sit in a different spot: they are historically part of the AI field, even without any learning involved — they're just not what most modern AI systems are built from anymore.

"Learning," the machine-learning approach specifically, means: you show the system a large number of examples (a photo labeled "cat," a thousand emails labeled "spam" or "not spam"), and an algorithm adjusts itself until it can make the right call on examples it has never seen. That adjustment process — and everything you can build once it works — is the rest of this journey: Machine Learning is where it actually happens.

🔥 Interview recall
  • AI is the broad field/goal: systems that perform tasks requiring intelligence.
  • Machine Learning is one major approach to AI, not a synonym for it — the system learns from data instead of following hand-written rules.
  • Classical rule-based and expert systems are historically part of AI too, even without any learning involved.
  • ML now dominates practical AI because it scales far better to messy, variable real-world problems — which is why this journey follows it specifically.
🎤 Say this in an interview
"AI is the broad field of building systems that perform tasks requiring intelligence — perception, reasoning, decision-making. Machine learning is one major approach within that field, where the system learns patterns from data instead of following hand-written rules; it's not a synonym for AI, just the approach that currently dominates most practical systems, because it scales far better to real-world variation than hand-written rules do."
⚠️ Common trap

AI isn't only "systems that learned from data." An autocomplete that just looks up a fixed dictionary, or a dashboard that flags "if sales < last month," are simple hand-coded rules, not AI — but that's because they don't perform a task requiring much intelligence, not because rules are automatically disqualified. Classical rule-based and expert systems genuinely are part of AI's history. What's true and narrower: nearly every AI system worth learning about today, including everything else in this journey, is built on machine learning, because it scales far better to complex, variable problems than hand-written rules do.

🔴 Rule-based AI

A person writes every "if this, then that." Still AI — predictable, but only handles cases someone thought of.

vs.
🟢 Learning-based AI (ML)

The mapping from input to output is learned from examples. Handles new cases the rules never saw.

▾ 💻 Tiny illustrative example 
# Rule-based — a human wrote this exact check
def is_spam_rules(email):
    return "win a prize" in email.lower()

# Machine learning — nobody wrote the rule; it was learned from labeled examples
# model.fit(emails, labels)  -> model learns its own decision boundary
def is_spam_ai(email):
    return model.predict(email)  # behavior came from training, not from us

Illustrative only — model here stands for whatever was trained on real examples; the point is that nobody hand-wrote its decision logic.
