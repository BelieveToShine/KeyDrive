Concept 4 of 19 · 🎓 Foundations

A neural network is the actual thing being stacked when you go "deep."

Deep Learning said "stack many layers." A neural network is what a layer is actually made of — a concrete, fairly simple computation, repeated many times over.

❓ "What is a neuron doing, mathematically, inside a neural network?"
👁 See it first
🎯 A neural network = many weighted-sum-then-decide units (neurons), connected in layers.
▶️ Watch it happen: one neuron, then a network
📖 Why did this need to exist?

"Stack many layers" is a shape, not a mechanism — Deep Learning needed an actual, concrete computation to repeat at every layer. Neural networks are that computation: a neuron takes several numeric inputs, multiplies each by its own weight, adds them up with a bias term, and passes the result through an activation function that decides what the neuron actually outputs.

The weights are exactly the "internal parameters" that Machine Learning's training process adjusts. Training a neural network means repeatedly nudging every weight, in every neuron, until the network's overall output gets closer to the right answer.

▾ Go one level deeper (60 seconds)

The activation function matters more than it looks. Without one, stacking layers would just be stacking simple weighted sums — which collapses back into one big weighted sum, no more powerful than a single layer. The activation function introduces a bend (a non-linearity) at every neuron, and it's that bend, repeated across many neurons and layers, that lets a deep network represent curved, complex relationships a straight line never could.

"Neuron" is a loose, decades-old metaphor from biology — the actual computation is just arithmetic (multiply, add, bend). Don't over-read the biology into it.

🔥 Interview recall
  • One neuron = weighted sum of its inputs + a bias, then an activation function.
  • A layer = many neurons computing in parallel on the same inputs.
  • A network = many layers, each feeding the next.
  • Training a network = adjusting every weight until outputs get closer to correct.
🎤 Say this in an interview
"A neural network is built from neurons, where each neuron multiplies its inputs by learned weights, sums them with a bias, and passes the result through an activation function. Layers stack these neurons in sequence, and training adjusts the weights so the network's output gets closer to the correct answer."
⚠️ Common trap

"Neuron" is a metaphor, not a biology lesson. A biological neuron is vastly more complex than a weighted sum and an activation function. In interviews and in practice, treat "neuron" as the name of a specific small computation — don't try to make it more biologically literal than that.

▾ 💻 Tiny illustrative example 
# One neuron, computed by hand
inputs  = [1500, 3, 10]        # size, bedrooms, age
weights = [0.0006, 0.12, -0.02]  # learned during training
bias    = -0.4

weighted_sum = sum(i * w for i, w in zip(inputs, weights)) + bias
output = activation(weighted_sum)   # -> e.g. 0.82

Illustrative numbers only — real weights come from training, not from anyone guessing them.
